# farm_ad_analysis
Samostalni projekat iz predmeta Istraživanje podataka 2 na Matematičkom fakultetu.
Skup podataka preuzet sa: https://archive.ics.uci.edu/dataset/218/farm+ads

## Za analizu korisceni su:
### Pravila pridruzivanja:
* fpgrowth

### Klasterovanje:
* KMeans
* BisectingKMeans
* AgglomerativeClustering
* hdbscan
* GaussianMixture

### Klasifikacija:
* BaggingClassifier
* RandomForestClassifier
* XGBoost
* Support Vector Machine (SGDClassifier)
* Logistic regression (SGDClassifier)
